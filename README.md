# 머신러닝 실험실

**파이썬 설치 없이 브라우저에서 머신러닝을 실제로 학습시켜 보는** 고등학교 수업용 웹앱입니다.
정보 · 인공지능 기초 · 데이터 과학의 머신러닝 단원에 씁니다.

## 쓰는 법
- 인터넷이 되면 Pages 주소를 열면 됩니다.
- 교실 인터넷이 불안하면 `dist/index.html` 한 파일을 나눠 주세요. 더블클릭하면 데이터까지 함께 열립니다.
- 학생 정보를 받거나 저장하지 않습니다. 문제 풀이 기록도 화면을 닫으면 사라집니다.

## 탭 다섯 개
1. **데이터 탐험실** — head · info · describe · groupby · 그래프 · 상관 히트맵
2. **전처리 실험실** — 결측치 처리 전후 비교 · 인코딩 · 훈련/검증 분리 · 스케일링 · 데이터 누수 실험
3. **모델 학습실** — 회귀 8종 · 분류 5종을 실제로 학습. 훈련·검증 점수로 과적합 진단, 혼동 행렬 · ROC · 임계값 표, 새 데이터 예측
4. **딥러닝 실험실** — 은닉층 · 노드 · 활성화 함수 · 드롭아웃을 바꾸며 손실 곡선을 실시간으로
5. **문제 풀기** — 10회차 96문제. 빈칸 채우기 · 고르기 · 오류 찾기 · 순서 맞추기.
   문제마다 「실험실에서 직접 해 보기」 단추로 같은 데이터의 실험실 탭이 열립니다.

## 실습 데이터 10종 (모두 가상 자료)
회귀 — 기말고사 점수 · 농작물 수확량 · 중고차 시세 · 광고 성과 · 직원 연봉 · 공정 양품률 · 주택 거래가
분류 — 가입자 이탈 · 대출 심사 · 제품 불량(불량 1%)

## 개발
```bash
npm install
npm start            # 개발 서버
npm run build        # dist/index.html 한 파일로 빌드
npm test             # 계산 점검 + 문제 은행 모양 점검
npm run verify       # 문제 코드를 진짜 파이썬으로 실행해 정답 확인 (pandas · scikit-learn 필요)
node test/sweep.mjs  # 데이터 10종 × 모델 전수 학습 점검
```
문제를 새로 쓰거나 고칠 때는 [`docs/문제-작성-규칙.md`](docs/문제-작성-규칙.md) 를 먼저 읽으세요.
